# Proposal

## Why

Разработка информационной системы «Электронный читальный зал библиотеки» с нуля. Необходима базовая функциональная версия (MVP), которая предоставит пользователям возможность работать с каталогом библиотеки и электронными документами, а библиотекарям — управлять этим каталогом.

## What Changes

- Создание системы электронного читального зала с двумя режимами работы: читатель и библиотекарь
- Реализация каталога документов с поиском по названию, автору и году издания
- Реализация просмотра карточки документа с полной информацией
- Реализация чтения электронных документов во встроенном просмотрщике
- Реализация CRUD операций для библиотекаря (добавление, редактирование, удаление документов)
- Реализация управления жанрами для библиотекаря
- Реализация модели данных: документ (1:1 файл), автор (N:M), жанр (N:M)
- Реализация простого переключателя режима (без регистрации пользователей)
- Поддержка форматов файлов: PDF, EPUB, DJVU, TXT, DOCX
- Физическое удаление документов с подтверждением и каскадным удалением связей

## Capabilities

### New Capabilities

- `catalog-management`: Управление каталогом документов — просмотр списка, поиск, фильтрация, сортировка
- `document-reading`: Чтение электронных документов — встроенный просмотрщик для различных форматов
- `document-crud`: CRUD операции для документов — добавление, редактирование, удаление документов библиотекарем
- `author-management`: Управление авторами — создание при добавлении документа, автодополнение, связь с документами
- `genre-management`: Управление жанрами — CRUD операции для библиотекаря, связь с документами
- `user-mode-switching`: Переключение режимов — простой выбор роли читатель/библиотекарь без аутентификации

### Modified Capabilities

(Нет существующих capabilities для модификации)

## Impact

- Создание новой системы с нуля
- Требуется реализация хранилища для метаданных документов, авторов, жанров
- Требуется реализация файлового хранилища для электронных документов
- Требуется реализация встроенного просмотрщика документов
- Влияние на будущие версии: архитектура должна поддерживать добавление регистрации, избранного, истории чтения
