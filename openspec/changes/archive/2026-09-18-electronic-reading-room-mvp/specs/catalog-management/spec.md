# Spec Delta

## Purpose

Предоставляет пользователям возможность просматривать каталог документов, выполнять поиск по метаданным и фильтровать результаты.

## ADDED Requirements

### Requirement: Просмотр каталога документов
Система ДОЛЖНА отображать список всех доступных документов с основной информацией (название, автор, год издания).

#### Scenario: Успешный просмотр каталога
- **WHEN** пользователь открывает каталог
- **THEN** система отображает список всех документов с указанием названия, автора и года издания

#### Scenario: Пустой каталог
- **WHEN** пользователь открывает каталог и документов нет
- **THEN** система отображает сообщение об отсутствии документов

### Requirement: Поиск документов
Система ДОЛЖНА позволять выполнять поиск документов по названию, автору и году издания.

#### Scenario: Поиск по названию
- **WHEN** пользователь вводит название в поле поиска
- **THEN** система возвращает документы, название которых содержит введенный текст

#### Scenario: Поиск по автору
- **WHEN** пользователь вводит имя автора в поле поиска
- **THEN** система возвращает документы, автором которых является указанный автор

#### Scenario: Поиск по году издания
- **WHEN** пользователь вводит год издания в поле поиска
- **THEN** система возвращает документы, изданные в указанном году

#### Scenario: Поиск без результатов
- **WHEN** пользователь выполняет поиск и нет совпадений
- **THEN** система отображает сообщение об отсутствии результатов

### Requirement: Просмотр карточки документа
Система ДОЛЖНА предоставлять детальную информацию о документе при выборе его из каталога.

#### Scenario: Успешный просмотр карточки
- **WHEN** пользователь выбирает документ из каталога
- **THEN** система отображает полную информацию: название, автор(ы), год издания, издательство, жанр(ы), аннотацию

### Requirement: Фильтрация по жанрам
Система ДОЛЖНА позволять фильтровать документы по жанрам.

#### Scenario: Фильтрация по одному жанру
- **WHEN** пользователь выбирает жанр для фильтрации
- **THEN** система отображает только документы с указанным жанром

#### Scenario: Фильтрация по нескольким жанрам
- **WHEN** пользователь выбирает несколько жанров
- **THEN** система отображает документы, имеющие хотя бы один из выбранных жанров

### Requirement: Сортировка каталога
Система ДОЛЖНА позволять сортировать документы по различным критериям.

#### Scenario: Сортировка по названию
- **WHEN** пользователь выбирает сортировку по названию
- **THEN** документы отображаются в алфавитном порядке по названию

#### Scenario: Сортировка по году издания
- **WHEN** пользователь выбирает сортировку по году издания
- **THEN** документы отображаются в порядке убывания года издания (новые сначала)

#### Scenario: Сортировка по автору
- **WHEN** пользователь выбирает сортировку по автору
- **THEN** документы отображаются в алфавитном порядке по фамилии автора
