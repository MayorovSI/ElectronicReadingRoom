# Spec Delta

## Purpose

Предоставляет пользователям возможность читать электронные документы во встроенном просмотрщике системы.

## ADDED Requirements

### Requirement: Открытие документа для чтения
Система ДОЛЖНА позволять открывать документ для чтения из карточки документа.

#### Scenario: Успешное открытие документа
- **WHEN** пользователь нажимает кнопку "Читать" в карточке документа
- **THEN** система открывает встроенный просмотрщик с содержимым документа

#### Scenario: Открытие PDF документа
- **WHEN** пользователь открывает документ в формате PDF
- **THEN** система отображает документ в просмотрщике с возможностью навигации по страницам

#### Scenario: Открытие EPUB документа
- **WHEN** пользователь открывает документ в формате EPUB
- **THEN** система отображает документ в просмотрщике с возможностью навигации по главам

#### Scenario: Открытие DJVU документа
- **WHEN** пользователь открывает документ в формате DJVU
- **THEN** система отображает документ в просмотрщике с возможностью навигации по страницам

#### Scenario: Открытие TXT документа
- **WHEN** пользователь открывает документ в формате TXT
- **THEN** система отображает текстовое содержимое документа

#### Scenario: Открытие DOCX документа
- **WHEN** пользователь открывает документ в формате DOCX
- **THEN** система отображает документ в просмотрщике

### Requirement: Навигация в просмотрщике
Система ДОЛЖНА предоставлять элементы управления для навигации по документу.

#### Scenario: Переход на следующую страницу
- **WHEN** пользователь нажимает кнопку "Следующая страница"
- **THEN** система отображает следующую страницу документа

#### Scenario: Переход на предыдущую страницу
- **WHEN** пользователь нажимает кнопку "Предыдущая страница"
- **THEN** система отображает предыдущую страницу документа

#### Scenario: Переход к конкретной странице
- **WHEN** пользователь вводит номер страницы
- **THEN** система отображает указанную страницу документа

### Requirement: Масштабирование документа
Система ДОЛЖНА позволять изменять масштаб отображения документа.

#### Scenario: Увеличение масштаба
- **WHEN** пользователь нажимает кнопку увеличения масштаба
- **THEN** система увеличивает размер отображения документа

#### Scenario: Уменьшение масштаба
- **WHEN** пользователь нажимает кнопку уменьшения масштаба
- **THEN** система уменьшает размер отображения документа

### Requirement: Закрытие просмотрщика
Система ДОЛЖНА позволять закрыть просмотрщик и вернуться к карточке документа.

#### Scenario: Закрытие просмотрщика
- **WHEN** пользователь нажимает кнопку закрытия
- **THEN** система закрывает просмотрщик и возвращает пользователя к карточке документа
