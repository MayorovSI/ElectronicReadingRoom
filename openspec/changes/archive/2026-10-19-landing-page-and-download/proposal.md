# Proposal

## Why

При входе на сайт пользователь сразу видит каталог без выбора роли, а навигация для библиотекаря (добавление документа, управление жанрами) не работает — NavLink ведёт на относительные маршруты без ведущего `/`, и Blazor не резолвит их. Кроме того, у читателя нет возможности скачать документ на свой компьютер, а у библиотекаря загрузка файлов уже реализована через multipart/form-data, но не проходит через валидацию на стороне клиента при отсутствии должной обратной связи.

Нужна стартовая страница с выбором роли, отдельная страница каталога, исправление навигации и добавление скачивания файлов.

## What Changes

- Добавить стартовую страницу (landing) с выбором роли: после выбора пользователь переходит на страницу каталога с инструментами, соответствующими выбранной роли
- Перенести маршрут каталога с `/` на `/catalog`; сделать `/` landing-страницей
- Исправить навигационные ссылки библиотекаря (добавить ведущий `/` к маршрутам `documents/add` и `genres`), чтобы они работали корректно
- Добавить API-эндпоинт для скачивания файла документа (с Content-Disposition: attachment)
- Добавить кнопку «Скачать» на странице просмотра документа и в карточке документа для читателя

## Capabilities

### New Capabilities
- `landing-page`: Стартовая страница с выбором роли и переходом к каталогу

### Modified Capabilities
- `catalog-management`: Каталог переносится на маршрут `/catalog` вместо `/`
- `document-reading`: Добавляется возможность скачивания документа на компьютер
- `user-mode-switching`: Выбор роли вынесен на отдельную landing-страницу; режим сохраняется при переходе в каталог

## Impact

- `Catalog.razor`: изменение маршрута с `/` на `/catalog`
- Новая страница `Landing.razor` на маршруте `/`
- `MainLayout.razor`: исправление NavLink-ов (`/documents/add`, `/genres`), условное отображение навигации
- `FilesController.cs`: добавление эндпоинта для скачивания с Content-Disposition
- `DocumentDetails.razor` и `DocumentViewer.razor`: добавление кнопки «Скачать»
- `ApiService.cs`: добавление метода для формирования URL скачивания
