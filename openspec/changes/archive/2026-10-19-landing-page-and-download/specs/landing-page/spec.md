# Spec Delta

## Purpose

Предоставляет стартовую страницу, на которой пользователь выбирает роль (читатель или библиотекарь) перед переходом к основному функционалу системы.

## ADDED Requirements

### Requirement: Отображение стартовой страницы
Система ДОЛЖНА отображать стартовую страницу при первом входе на сайт, на которой пользователю предлагается выбрать роль.

#### Scenario: Первый вход на сайт
- **WHEN** пользователь открывает сайт (маршрут `/`)
- **THEN** система отображает стартовую страницу с выбором роли: «Читатель» и «Библиотекарь»

#### Scenario: Повторный вход без выбранной роли
- **WHEN** пользователь возвращается на стартовую страницу
- **THEN** система отображает страницу выбора роли заново

### Requirement: Выбор роли на стартовой странице
Система ДОЛЖНА позволять пользователю выбрать роль на стартовой странице и перейти к каталогу.

#### Scenario: Выбор роли «Читатель»
- **WHEN** пользователь нажимает кнопку «Читатель» на стартовой странице
- **THEN** система устанавливает режим «Читатель» и перенаправляет пользователя на страницу каталога

#### Scenario: Выбор роли «Библиотекарь»
- **WHEN** пользователь нажимает кнопку «Библиотекарь» на стартовой странице
- **THEN** система устанавливает режим «Библиотекарь» и перенаправляет пользователя на страницу каталога

### Requirement: Переход из каталога на стартовую страницу
Система ДОЛЖНА позволять пользователю вернуться на стартовую страницу для смены роли.

#### Scenario: Возврат на стартовую страницу
- **WHEN** пользователь нажимает элемент навигации «Сменить роль»
- **THEN** система перенаправляет пользователя на стартовую страницу выбора роли
