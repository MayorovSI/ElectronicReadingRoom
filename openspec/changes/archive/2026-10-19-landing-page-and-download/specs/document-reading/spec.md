# Spec Delta

## ADDED Requirements

### Requirement: Скачивание документа
Система ДОЛЖНА позволять пользователю скачать файл документа на свой компьютер.

#### Scenario: Скачивание из карточки документа
- **WHEN** пользователь нажимает кнопку «Скачать» на странице документа
- **THEN** система инициирует скачивание файла документа на компьютер пользователя с оригинальным именем файла

#### Scenario: Скачивание из просмотрщика
- **WHEN** пользователь нажимает кнопку «Скачать» в просмотрщике документа
- **THEN** система инициирует скачивание файла документа на компьютер пользователя

#### Scenario: Скачивание недоступного файла
- **WHEN** пользователь пытается скачать документ, файл которого отсутствует
- **THEN** система отображает сообщение об ошибке
