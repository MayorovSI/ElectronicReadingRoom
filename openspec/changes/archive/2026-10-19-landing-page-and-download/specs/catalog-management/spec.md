# Spec Delta

## MODIFIED Requirements

### Requirement: Просмотр каталога документов
Система ДОЛЖНА отображать список всех доступных документов с основной информацией (название, автор, год издания) на отдельной странице каталога (маршрут `/catalog`).

#### Scenario: Успешный просмотр каталога
- **WHEN** пользователь переходит на страницу каталога (`/catalog`)
- **THEN** система отображает список всех документов с указанием названия, автора и года издания

#### Scenario: Пустой каталог
- **WHEN** пользователь открывает каталог и документов нет
- **THEN** система отображает сообщение об отсутствии документов

#### Scenario: Переход из навигации в каталог
- **WHEN** пользователь нажимает ссылку «Каталог» в навигации
- **THEN** система перенаправляет на страницу `/catalog`
