# Spec Delta

## MODIFIED Requirements

### Requirement: Переключение режима работы
Система ДОЛЖНА позволять переключаться между режимами читателя и библиотекаря через стартовую страницу выбора роли и через навигацию внутри приложения.

#### Scenario: Переключение на стартовой странице
- **WHEN** пользователь выбирает роль на стартовой странице
- **THEN** система устанавливает выбранный режим и перенаправляет на страницу каталога

#### Scenario: Переключение в режим читателя
- **WHEN** пользователь выбирает режим «Читатель»
- **THEN** система отображает функции читателя: просмотр каталога, поиск, чтение документов

#### Scenario: Переключение в режим библиотекаря
- **WHEN** пользователь выбирает режим «Библиотекарь»
- **THEN** система отображает функции библиотекаря: управление каталогом, управление жанрами, CRUD операции

#### Scenario: Переключение режима во время работы
- **WHEN** пользователь переключает режим во время работы с системой
- **THEN** система изменяет доступные функции согласно новому режиму

### Requirement: Режим по умолчанию
Система ДОЛЖНА устанавливать режим по умолчанию при запуске и предлагать выбор роли на стартовой странице.

#### Scenario: Режим читателя по умолчанию
- **WHEN** пользователь впервые открывает систему
- **THEN** система устанавливает режим «Читатель» по умолчанию

#### Scenario: Возврат на стартовую страницу
- **WHEN** пользователь переходит на маршрут `/`
- **THEN** система отображает стартовую страницу выбора роли независимо от ранее выбранного режима
