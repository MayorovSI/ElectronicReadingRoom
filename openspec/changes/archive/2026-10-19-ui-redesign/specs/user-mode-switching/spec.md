# Spec Delta

## ADDED Requirements

### Requirement: Визуально выразительный лендинг
Система ДОЛЖНА отображать лендинг выбора роли с двумя крупными карточками (читатель/библиотекарь), использующими градиенты, иконки и hover-анимации согласно дизайн-системе.

#### Scenario: Отображение карточек ролей
- **WHEN** пользователь открывает лендинг
- **THEN** отображаются две карточки: «Читатель» (с иконкой книги, синий акцент) и «Библиотекарь» (с иконкой стопки книг, янтарный акцент)

#### Scenario: Hover-эффект на карточке роли
- **WHEN** пользователь наводит курсор на карточку роли
- **THEN** карточка плавно масштабируется (scale 1.03) и усиливается тень с длительностью перехода из дизайн-системы

#### Scenario: Адаптивность лендинга
- **WHEN** ширина экрана < 768px
- **THEN** карточки ролей отображаются в одну колонку с сохранением всех визуальных эффектов

### Requirement: Обновлённая навигационная панель
Система ДОЛЖНА отображать навигационную панель с кастомной стилизацией: логотип с иконкой, индикатор активного раздела, плавные переходы между пунктами меню.

#### Scenario: Индикация активного раздела
- **WHEN** пользователь находится на странице каталога
- **THEN** пункт «Каталог» в навигации подсвечен подчёркиванием или изменением цвета

#### Scenario: Адаптивная навигация на мобильных
- **WHEN** ширина экрана < 768px
- **THEN** навигационное меню сворачивается в гамбургер-меню

### Requirement: Индикатор режима с иконкой
Система ДОЛЖНА отображать текущий режим в навигации с иконкой и цветовой индикацией (синий для читателя, янтарный для библиотекаря).

#### Scenario: Отображение режима читателя
- **WHEN** выбран режим «Читатель»
- **THEN** в навигации отображается бейдж синего цвета с иконкой книги и текстом «Читатель»

#### Scenario: Отображение режима библиотекаря
- **WHEN** выбран режим «Библиотекарь»
- **THEN** в навигации отображается бейдж янтарного цвета с иконкой стопки книг и текстом «Библиотекарь»
