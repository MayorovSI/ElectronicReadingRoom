# Spec Delta

## ADDED Requirements

### Requirement: Стилизованная таблица жанров
Система ДОЛЖНА отображать список жанров в стилизованной таблице с hover-эффектами строк, плавным появлением inline-редактирования и иконками действий.

#### Scenario: Hover-эффект строки таблицы
- **WHEN** пользователь наводит курсор на строку жанра
- **THEN** строка плавно меняет фон с длительностью перехода из дизайн-системы

#### Scenario: Inline-редактирование с анимацией
- **WHEN** пользователь нажимает «Редактировать» у жанра
- **THEN** название жанра плавно заменяется на поле ввода с кнопками «Сохранить» и «Отмена»

### Requirement: Стилизованная форма добавления жанра
Система ДОЛЖНА отображать форму добавления жанра сгруппированной в карточке с кнопкой, использующей акцентный цвет.

#### Scenario: Отображение формы добавления
- **WHEN** библиотекарь открывает страницу жанров
- **THEN** форма добавления отображается в карточке с полем ввода и кнопкой акцентного цвета
