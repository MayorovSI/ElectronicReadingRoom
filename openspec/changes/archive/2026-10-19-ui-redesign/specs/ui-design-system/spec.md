# Spec Delta

## Purpose

Определяет единую дизайн-систему проекта на основе CSS-переменных: палитру цветов, типографику, токены отступов, скруглений, теней и анимаций, обеспечивающую визуальную согласованность всех компонентов интерфейса ElectronicReadingRoom.

## ADDED Requirements

### Requirement: Цветовая палитра на CSS-переменных
Система ДОЛЖНА предоставлять палитру цветов через CSS-переменные, определённые в `:root`, включая основной цвет, акцентный, фоновый, текстовый, цвета успеха, предупреждения и ошибки.

#### Scenario: Использование основного цвета
- **WHEN** любой компонент использует CSS-переменную основного цвета
- **THEN** применяется единый основной цвет из дизайн-системы

#### Scenario: Переопределение цвета через переменную
- **WHEN** переменная цвета изменяется в `:root`
- **THEN** все компоненты, использующие эту переменную, автоматически получают новое значение

### Requirement: Типографика
Система ДОЛЖНА определять базовый шрифт, размеры заголовков (h1–h6) и межстрочный интервал через CSS-переменные.

#### Scenario: Заголовок первого уровня
- **WHEN** компонент использует `<h1>` или эквивалентный класс
- **THEN** заголовок отображается с размером и жирностью согласно дизайн-системе

#### Scenario: Основной текст
- **WHEN** компонент отображает параграф с текстом
- **THEN** текст использует базовый шрифт и межстрочный интервал из дизайн-системы

### Requirement: Токены отступов
Система ДОЛЖНА определять шкалу отступов (xs, sm, md, lg, xl) через CSS-переменные для единообразного spacing.

#### Scenario: Применение стандартного отступа
- **WHEN** компонент использует CSS-переменную отступа
- **THEN** применяется значение из шкалы отступов дизайн-системы

### Requirement: Скругления и тени
Система ДОЛЖНА определять токены скруглений (sm, md, lg) и теней (sm, md, lg) через CSS-переменные.

#### Scenario: Применение тени к карточке
- **WHEN** компонент карточки использует CSS-переменную тени
- **THEN** карточка отображается с тенью согласно дизайн-системе

#### Scenario: Скругление углов
- **WHEN** компонент использует CSS-переменную скругления
- **THEN** углы элемента скругляются согласно значению из дизайн-системы

### Requirement: Анимации и переходы
Система ДОЛЖНА определять длительности и easing-функции для переходов и анимаций через CSS-переменные.

#### Scenario: Hover-эффект на интерактивном элементе
- **WHEN** пользователь наводит курсор на интерактивный элемент
- **THEN** применяется плавный переход с длительностью из дизайн-системы

#### Scenario: Появление элемента
- **WHEN** элемент добавляется в DOM (рендерится впервые)
- **THEN** применяется анимация появления с параметрами из дизайн-системы

### Requirement: Импорт шрифта
Система ДОЛЖНА подключать нестандартный веб-шрифт (Google Fonts: Inter) для основного текста и заголовков.

#### Scenario: Отображение текста
- **WHEN** страница загружается в браузере
- **THEN** текст отображается шрифтом Inter с fallback на системные sans-serif
