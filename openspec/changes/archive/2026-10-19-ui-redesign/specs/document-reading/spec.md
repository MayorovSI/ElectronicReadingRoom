# Spec Delta

## ADDED Requirements

### Requirement: Минималистичный тулбар просмотрщика
Система ДОЛЖНА отображать тулбар просмотрщика в минималистичном стиле: полупрозрачный фон, сгруппированные кнопки навигации и зума, скрытие неактивных кнопок.

#### Scenario: Отображение тулбара
- **WHEN** пользователь открывает просмотрщик документа
- **THEN** тулбар отображается с полупрозрачным тёмным фоном, кнопками «Назад/Вперёд», полем номера страницы и зумом

#### Scenario: Адаптивный тулбар на мобильных
- **WHEN** просмотрщик открыт на экране < 768px
- **THEN** кнопки тулбара отображаются в одну строку с уменьшенными отступами

### Requirement: Фокус на контенте
Система ДОЛЖНА отображать содержимое документа на нейтральном фоне (`--color-bg`) с максимальной доступной площадью для чтения.

#### Scenario: Отображение контента
- **WHEN** пользователь просматривает документ
- **THEN** содержимое занимает всю доступную высоту viewport за вычетом тулбара, без отвлекающих элементов

### Requirement: Кнопка скачивания в просмотрщике
Система ДОЛЖНА отображать кнопку скачивания документа в тулбаре просмотрщика с иконкой загрузки.

#### Scenario: Скачивание из просмотрщика
- **WHEN** пользователь нажимает кнопку скачивания в просмотрщике
- **THEN** браузер начинает скачивание файла документа
