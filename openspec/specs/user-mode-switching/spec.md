# Spec

## Purpose

Предоставляет простой механизм переключения между режимами работы системы (читатель и библиотекарь) без необходимости регистрации или аутентификации пользователей.

## Requirements

### Requirement: Переключение режима работы
Система ДОЛЖНА позволять переключаться между режимами читателя и библиотекаря через стартовую страницу выбора роли и через навигацию внутри приложения.

#### Scenario: Переключение на стартовой странице
- **WHEN** пользователь выбирает роль на стартовой странице
- **THEN** система устанавливает выбранный режим и перенаправляет на страницу каталога

#### Scenario: Переключение в режим читателя
- **WHEN** пользователь выбирает режим «Читатель»
- **THEN** система отображает функции читателя: просмотр каталога, поиск, чтение документов

#### Scenario: Переключение в режим библиотекаря
- **WHEN** пользователь выбирает режим «Библиотекарь»
- **THEN** система отображает функции библиотекаря: управление каталогом, управление жанрами, CRUD операции

#### Scenario: Переключение режима во время работы
- **WHEN** пользователь переключает режим во время работы с системой
- **THEN** система изменяет доступные функции согласно новому режиму

### Requirement: Ограничение доступа по режиму
Система ДОЛЖНА ограничивать доступ к функциям согласно выбранному режиму.

#### Scenario: Доступ читателя к функциям
- **WHEN** выбран режим "Читатель"
- **THEN** пользователю доступны: просмотр каталога, поиск, просмотр карточки документа, чтение документов

#### Scenario: Доступ библиотекаря к функциям
- **WHEN** выбран режим "Библиотекарь"
- **THEN** пользователю доступны: просмотр каталога, поиск, просмотр карточки документа, чтение документов, добавление/редактирование/удаление документов, управление жанрами

#### Scenario: Недоступность функций библиотекаря для читателя
- **WHEN** выбран режим "Читатель"
- **THEN** функции управления каталогом и жанрами скрыты или недоступны

#### Scenario: Недоступность функций читателя для библиотекаря
- **WHEN** выбран режим "Библиотекарь"
- **THEN** функции чтения и просмотра каталога остаются доступны

### Requirement: Отображение текущего режима
Система ДОЛЖНА четко отображать текущий режим работы.

#### Scenario: Индикация режима читателя
- **WHEN** выбран режим "Читатель"
- **THEN** система отображает индикатор текущего режима

#### Scenario: Индикация режима библиотекаря
- **WHEN** выбран режим "Библиотекарь"
- **THEN** система отображает индикатор текущего режима

### Requirement: Режим по умолчанию
Система ДОЛЖНА устанавливать режим по умолчанию при запуске и предлагать выбор роли на стартовой странице.

#### Scenario: Режим читателя по умолчанию
- **WHEN** пользователь впервые открывает систему
- **THEN** система устанавливает режим «Читатель» по умолчанию

#### Scenario: Возврат на стартовую страницу
- **WHEN** пользователь переходит на маршрут `/`
- **THEN** система отображает стартовую страницу выбора роли независимо от ранее выбранного режима

### Requirement: Визуально выразительный лендинг
Система ДОЛЖНА отображать лендинг выбора роли с двумя крупными карточками (читатель/библиотекарь), использующими градиенты, иконки и hover-анимации согласно дизайн-системе.

#### Scenario: Отображение карточек ролей
- **WHEN** пользователь открывает лендинг
- **THEN** отображаются две карточки: «Читатель» (с иконкой книги, синий акцент) и «Библиотекарь» (с иконкой стопки книг, янтарный акцент)

#### Scenario: Hover-эффект на карточке роли
- **WHEN** пользователь наводит курсор на карточку роли
- **THEN** карточка плавно масштабируется (scale 1.03) и усиливается тень с длительностью перехода из дизайн-системы

#### Scenario: Адаптивность лендинга
- **WHEN** ширина экрана < 768px
- **THEN** карточки ролей отображаются в одну колонку с сохранением всех визуальных эффектов

### Requirement: Обновлённая навигационная панель
Система ДОЛЖНА отображать навигационную панель с кастомной стилизацией: логотип с иконкой, индикатор активного раздела, плавные переходы между пунктами меню.

#### Scenario: Индикация активного раздела
- **WHEN** пользователь находится на странице каталога
- **THEN** пункт «Каталог» в навигации подсвечен подчёркиванием или изменением цвета

#### Scenario: Адаптивная навигация на мобильных
- **WHEN** ширина экрана < 768px
- **THEN** навигационное меню сворачивается в гамбургер-меню

### Requirement: Индикатор режима с иконкой
Система ДОЛЖНА отображать текущий режим в навигации с иконкой и цветовой индикацией (синий для читателя, янтарный для библиотекаря).

#### Scenario: Отображение режима читателя
- **WHEN** выбран режим «Читатель»
- **THEN** в навигации отображается бейдж синего цвета с иконкой книги и текстом «Читатель»

#### Scenario: Отображение режима библиотекаря
- **WHEN** выбран режим «Библиотекарь»
- **THEN** в навигации отображается бейдж янтарного цвета с иконкой стопки книг и текстом «Библиотекарь»
