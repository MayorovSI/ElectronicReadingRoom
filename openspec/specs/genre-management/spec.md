# Spec

## Purpose

Предоставляет библиотекарям возможность управлять жанрами: добавлять новые жанры, редактировать существующие и удалять жанры, а также связывать жанры с документами.

## Requirements

### Requirement: Добавление жанра
Система ДОЛЖНА позволять библиотекарю добавлять новый жанр в систему.

#### Scenario: Успешное добавление жанра
- **WHEN** библиотекарь вводит название нового жанра и нажимает кнопку "Добавить"
- **THEN** система создает новый жанр и делает его доступным для использования

#### Scenario: Добавление дубликата жанра
- **WHEN** библиотекарь пытается добавить жанр с уже существующим названием
- **THEN** система отображает сообщение об ошибке и не создает дубликат

### Requirement: Редактирование жанра
Система ДОЛЖНА позволять библиотекарю изменять название существующего жанра.

#### Scenario: Успешное редактирование жанра
- **WHEN** библиотекарь изменяет название жанра и нажимает кнопку "Сохранить"
- **THEN** система обновляет название жанра, изменения отражаются во всех связанных документах

#### Scenario: Редактирование на существующее название
- **WHEN** библиотекарь пытается изменить название жанра на уже существующее
- **THEN** система отображает сообщение об ошибке и не сохраняет изменения

### Requirement: Удаление жанра
Система ДОЛЖНА позволять библиотекарю удалять жанр из системы.

#### Scenario: Успешное удаление неиспользуемого жанра
- **WHEN** библиотекарь удаляет жанр, который не связан ни с одним документом
- **THEN** система удаляет жанр из системы

#### Scenario: Удаление используемого жанра
- **WHEN** библиотекарь пытается удалить жанр, связанный с документами
- **THEN** система удаляет связи между жанром и документами, а затем удаляет сам жанр

### Requirement: Просмотр списка жанров
Система ДОЛЖНА отображать список всех доступных жанров.

#### Scenario: Просмотр всех жанров
- **WHEN** библиотекарь открывает раздел управления жанрами
- **THEN** система отображает список всех жанров в системе

#### Scenario: Пустой список жанров
- **WHEN** библиотекарь открывает раздел управления жанрами и жанров нет
- **THEN** система отображает сообщение об отсутствии жанров

### Requirement: Связывание жанров с документами
Система ДОЛЖНА позволять связывать один или несколько жанров с документом.

#### Scenario: Добавление жанра к документу
- **WHEN** библиотекарь выбирает жанр для документа
- **THEN** система создает связь между документом и жанром

#### Scenario: Удаление жанра из документа
- **WHEN** библиотекарь удаляет жанр из списка жанров документа
- **THEN** система удаляет связь между документом и жанром

#### Scenario: Документ с несколькими жанрами
- **WHEN** библиотекарь добавляет несколько жанров к документу
- **THEN** система создает связи между документом и всеми выбранными жанрами

#### Scenario: Документ без жанров
- **WHEN** библиотекарь не выбирает жанры для документа
- **THEN** система сохраняет документ без связей с жанрами

### Requirement: Стилизованная таблица жанров
Система ДОЛЖНА отображать список жанров в стилизованной таблице с hover-эффектами строк, плавным появлением inline-редактирования и иконками действий.

#### Scenario: Hover-эффект строки таблицы
- **WHEN** пользователь наводит курсор на строку жанра
- **THEN** строка плавно меняет фон с длительностью перехода из дизайн-системы

#### Scenario: Inline-редактирование с анимацией
- **WHEN** пользователь нажимает «Редактировать» у жанра
- **THEN** название жанра плавно заменяется на поле ввода с кнопками «Сохранить» и «Отмена»

### Requirement: Стилизованная форма добавления жанра
Система ДОЛЖНА отображать форму добавления жанра сгруппированной в карточке с кнопкой, использующей акцентный цвет.

#### Scenario: Отображение формы добавления
- **WHEN** библиотекарь открывает страницу жанров
- **THEN** форма добавления отображается в карточке с полем ввода и кнопкой акцентного цвета
