# Spec

## Purpose

Предоставляет возможность управления авторами документов, включая автоматическое создание записей авторов при добавлении документов и автодополнение существующих авторов.

## Requirements

### Requirement: Создание автора при добавлении документа
Система ДОЛЖНА автоматически создавать запись автора при добавлении документа, если автор не существует.

#### Scenario: Создание нового автора
- **WHEN** библиотекарь вводит имя нового автора при добавлении документа
- **THEN** система создает новую запись автора и связывает её с документом

#### Scenario: Повторное использование существующего автора
- **WHEN** библиотекарь выбирает существующего автора из списка автодополнения
- **THEN** система использует существующую запись автора без создания дубликата

### Requirement: Автодополнение авторов
Система ДОЛЖНА предоставлять автодополнение при вводе имени автора.

#### Scenario: Автодополнение при вводе
- **WHEN** библиотекарь начинает вводить имя автора
- **THEN** система отображает список существующих авторов, чьи имена содержат введенный текст

#### Scenario: Выбор автора из списка автодополнения
- **WHEN** библиотекарь выбирает автора из списка автодополнения
- **THEN** система заполняет поле именем выбранного автора

#### Scenario: Отсутствие совпадений
- **WHEN** библиотекарь вводит текст, который не совпадает ни с одним существующим автором
- **THEN** система не отображает список автодополнения, позволяя создать нового автора

### Requirement: Множественные авторы
Система ДОЛЖНА позволять указывать несколько авторов для одного документа.

#### Scenario: Добавление нескольких авторов
- **WHEN** библиотекарь добавляет нескольких авторов при создании документа
- **THEN** система создает связи между документом и всеми указанными авторами

#### Scenario: Удаление автора из документа
- **WHEN** библиотекарь удаляет автора из списка авторов документа
- **THEN** система удаляет связь между документом и автором, но не удаляет самого автора

### Requirement: Просмотр списка авторов
Система ДОЛЖНА отображать список всех авторов в карточке документа.

#### Scenario: Отображение авторов документа
- **WHEN** пользователь просматривает карточку документа
- **THEN** система отображает всех авторов, связанных с документом

### Requirement: Уникальность имен авторов
Система ДОЛЖНА обеспечивать уникальность имен авторов в системе.

#### Scenario: Предотвращение дублирования авторов
- **WHEN** библиотекарь пытается создать автора с уже существующим именем
- **THEN** система использует существующую запись автора вместо создания дубликата
