# Spec

## Purpose

Предоставляет пользователям возможность просматривать каталог документов, выполнять поиск по метаданным и фильтровать результаты.

## Requirements

### Requirement: Просмотр каталога документов
Система ДОЛЖНА отображать список всех доступных документов с основной информацией (название, автор, год издания) на отдельной странице каталога (маршрут `/catalog`).

#### Scenario: Успешный просмотр каталога
- **WHEN** пользователь переходит на страницу каталога (`/catalog`)
- **THEN** система отображает список всех документов с указанием названия, автора и года издания

#### Scenario: Пустой каталог
- **WHEN** пользователь открывает каталог и документов нет
- **THEN** система отображает сообщение об отсутствии документов

#### Scenario: Переход из навигации в каталог
- **WHEN** пользователь нажимает ссылку «Каталог» в навигации
- **THEN** система перенаправляет на страницу `/catalog`

### Requirement: Поиск документов
Система ДОЛЖНА позволять выполнять поиск документов по названию, автору и году издания.

#### Scenario: Поиск по названию
- **WHEN** пользователь вводит название в поле поиска
- **THEN** система возвращает документы, название которых содержит введенный текст

#### Scenario: Поиск по автору
- **WHEN** пользователь вводит имя автора в поле поиска
- **THEN** система возвращает документы, автором которых является указанный автор

#### Scenario: Поиск по году издания
- **WHEN** пользователь вводит год издания в поле поиска
- **THEN** система возвращает документы, изданные в указанном году

#### Scenario: Поиск без результатов
- **WHEN** пользователь выполняет поиск и нет совпадений
- **THEN** система отображает сообщение об отсутствии результатов

### Requirement: Просмотр карточки документа
Система ДОЛЖНА предоставлять детальную информацию о документе при выборе его из каталога.

#### Scenario: Успешный просмотр карточки
- **WHEN** пользователь выбирает документ из каталога
- **THEN** система отображает полную информацию: название, автор(ы), год издания, издательство, жанр(ы), аннотацию

### Requirement: Фильтрация по жанрам
Система ДОЛЖНА позволять фильтровать документы по жанрам.

#### Scenario: Фильтрация по одному жанру
- **WHEN** пользователь выбирает жанр для фильтрации
- **THEN** система отображает только документы с указанным жанром

#### Scenario: Фильтрация по нескольким жанрам
- **WHEN** пользователь выбирает несколько жанров
- **THEN** система отображает документы, имеющие хотя бы один из выбранных жанров

### Requirement: Сортировка каталога
Система ДОЛЖНА позволять сортировать документы по различным критериям.

#### Scenario: Сортировка по названию
- **WHEN** пользователь выбирает сортировку по названию
- **THEN** документы отображаются в алфавитном порядке по названию

#### Scenario: Сортировка по году издания
- **WHEN** пользователь выбирает сортировку по году издания
- **THEN** документы отображаются в порядке убывания года издания (новые сначала)

#### Scenario: Сортировка по автору
- **WHEN** пользователь выбирает сортировку по автору
- **THEN** документы отображаются в алфавитном порядке по фамилии автора

### Requirement: Визуальное оформление карточек документов
Система ДОЛЖНА отображать карточки документов в каталоге с использованием дизайн-токенов: тени карточек, скругления, hover-эффекты, плавные переходы.

#### Scenario: Отображение карточки документа
- **WHEN** пользователь просматривает каталог
- **THEN** каждая карточка отображается с тенью (`--shadow-sm`), скруглением (`--radius-md`) и белым фоном

#### Scenario: Hover-эффект на карточке
- **WHEN** пользователь наводит курсор на карточку документа
- **THEN** карточка плавно приподнимается (увеличение тени до `--shadow-md` и translateY) с длительностью перехода из дизайн-системы

### Requirement: Индикатор формата файла
Система ДОЛЖНА отображать формат файла документа на карточке каталога в виде стилизованного бейджа с иконкой формата.

#### Scenario: Отображение формата PDF
- **WHEN** документ имеет формат PDF
- **THEN** на карточке отображается бейдж «PDF» с иконкой и цветом формата

#### Scenario: Отображение формата DOCX
- **WHEN** документ имеет формат DOCX
- **THEN** на карточке отображается бейдж «DOCX» с соответствующим цветом

### Requirement: Предпросмотр первой страницы документа
Система ДОЛЖНА отображать в карточке документа предпросмотр его первой страницы для форматов PDF, EPUB, DJVU, DOCX и TXT. Предпросмотр одной карточки не ДОЛЖЕН отображаться в карточке другого документа при переключении страниц каталога.

#### Scenario: Предпросмотр поддерживаемых форматов
- **WHEN** в каталоге отображается документ формата PDF, EPUB, DJVU, DOCX или TXT
- **THEN** его карточка отображает первую страницу документа с помощью соответствующего формату предпросмотра

#### Scenario: Переключение страницы каталога
- **WHEN** пользователь переходит на другую страницу каталога
- **THEN** предпросмотр каждой карточки соответствует формату и файлу этого документа

### Requirement: Сетка каталога с CSS Grid
Система ДОЛЖНА использовать адаптивную CSS Grid-сетку для отображения карточек, автоматически подстраивая количество колонок под ширину экрана.

#### Scenario: Рабочий стол (≥1200px)
- **WHEN** ширина экрана ≥ 1200px
- **THEN** карточки отображаются в 3 колонки

#### Scenario: Планшет (768–1199px)
- **WHEN** ширина экрана 768–1199px
- **THEN** карточки отображаются в 2 колонки

#### Scenario: Мобильный (<768px)
- **WHEN** ширина экрана < 768px
- **THEN** карточки отображаются в 1 колонку на всю ширину
